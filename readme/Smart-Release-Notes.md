# Bettbox Smart 1.19.4 · Smart 内核更新

- 改进 Smart 节点过滤和自动选路：区分 TCP/UDP 的失败记录与选路缓存，临时避让节点时保留原有选路，并优化大规则集与 GeoSite 的目标分类。
- 改进出口地区与 ASN 探测，支持按目标识别实际落地出口，并减少重复探测及站点拒绝响应造成的节点误判。
- 改进连接异常和丢包判定：按有效采样窗口统计 TCP 丢包，对重复确认的丢包分级避让，减少短连接和暂时停滞导致的误过滤。
- 更新 LightGBM 特征编码，加入出口地区与 ASN 特征，兼容不同特征数量的模型；旧格式的采集 CSV 自动备份后重建。
- 修复配置重载后 Fake-IP 分配状态丢失、旧域名映射被新分配覆盖的问题。
- 限制 DoH 建连及 TLS 握手耗时，避免已结束的查询留下持续累积的建连任务；更新 Mieru 至 3.38.1。
