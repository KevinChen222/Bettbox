# Bettbox Smart 1.19.4 · 代理链路

- 新增「工具 → 代理链路」，支持组合配置节点、策略组与 HTTP(S)/SOCKS5 端点，创建多跳代理并预览路径。
- 支持调整各跳顺序、绑定已有策略组，以及链路编辑、复制、启停、删除和 JSON 导入导出。
- 支持自定义 HTTP、file 和 inline Provider；节点引用按 Provider 名与节点名保存，订阅重新排序不会改变所选节点。
- 可从链路创建本地配置或导出 YAML；绑定原订阅的链路会读取最新节点参数，不修改订阅原文件。
- 链路库随本地/WebDAV 备份恢复，遇到缺失节点、组循环或路径超限时提供错误提示。
- 新版本先以 test 测试版发布，下一版发布后将上一版转为正式版。
