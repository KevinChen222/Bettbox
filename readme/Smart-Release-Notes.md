# Bettbox Smart 1.19.5

- 合并 Bettbox 1.19.5，更新编辑器、Rust 脚本引擎、日志、仪表盘及桌面侧栏，改善 Android 服务生命周期与配置更新。
- 更新 Smart Alpha 内核，保留 Smart 自动选路、固定节点、单次及整组测速，以及 LightGBM 模型同步。
- 代理链路适配新版 Go 配置覆写流程，保留链路保存、备份恢复、快照导出及失效链路隔离；订阅更新继续保留本地添加的节点和 Provider。
- 保留自定义页面标题、个人 fork 更新渠道及 Android 独立包名。Linux DEB 沿用 Ubuntu 24.04 依赖和 OpenJDK 17 JNI 路径，适配新版网络 capabilities 授权。
