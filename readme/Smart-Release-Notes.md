# Bettbox Smart 1.19.4 · 外部节点导入与 Smart 更新

- 配置编辑页新增「添加节点」按钮，支持手动粘贴分享链接或 Mihomo YAML/JSON 节点，以及从订阅链接仅导入节点；追加到当前配置的 `proxies` 末尾，保存后生效。
- 链路的「添加一跳」窗口新增外部节点入口，外部节点随链路保留并进入生成配置，不修改来源配置，支持自建 SS2022 等落地节点。
- 两个入口共用带遮罩的展开动画，点击空白处收起；节点参数由当前内核校验，同名自动分配后缀。
- Smart 回调层增加一次性关闭保护，减少重复关闭向下传递；保留 tracker 层的重复关闭防护。
- Smart 改进传输中途错误记录，对零流量和丢包异常采用重复确认，减少误判后的关闭与重新选路；支持更深的连接包装统计。
- WireGuard 设备与协议栈改为按需初始化，并加强取消、失败及关闭时的资源清理。
- Android 安装包统一为 arm64-v8a，减少多架构编译开销。
- 修正「关于」页面的 Bettbox 名称大小写，并加强个人自用、合法网络调试及禁止违法用途的声明。
