# Bettbox Smart 1.19.4 · 2026-10-04

- 新增 Android `arm64-v8a` 单架构 APK，减少支持该架构设备的下载体积；继续提供通用 APK 和 Windows x64 便携包。
- 修复 Smart 自动模式的虚拟节点名称被当作真实节点测速，导致延迟一直转圈的问题。
- 修复测速失败后的状态清理，失败时结束动画并显示超时，支持再次测速。
- Smart 组自己的测速按钮会测试全部可测速成员、解除手动固定并恢复自动选路；搜索筛选不会缩减该组的测速范围。
- 其他策略组中的 Smart 卡片只测速一次；手动固定时测速固定节点，自动模式时由 Smart 为测速地址选路，不触发整组测速或解除固定选择。
- 安卓 APK 沿用上一版的持久自用签名；后续构建和维护流程同步增加 arm64 包及 Smart 测速处理。
