# Bettbox Smart 1.19.7

- 合并 Bettbox 1.19.6 正式版及 main 的后续修正，更新首页出站模式、移动导航动画与卡片/对话框样式；改善编辑器缩放、进程图标加载和 Android 自定义字体。
- 支持脚本配置独立应用规则覆写，完善运行配置预览与策略组禁用处理。
- Linux DEB 内嵌限定 DNS 操作的 Polkit 规则，使用网络 capabilities 授权；支持 Linux 系统 DNS 管理与网络切换后恢复。
- 支持按需禁用桌面 Impeller，并同步 macOS Dock 图标显示。
- 保留 Smart 自动选路、固定节点、测速和 LightGBM 模型同步，以及代理链路、节点导入、自定义页面标题和个人 fork 更新渠道。
