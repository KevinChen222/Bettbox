# Bettbox Smart 1.19.4 · 链路配置管理与页面标题

- 链路直接「保存」会写入原配置 YAML，同一配置可添加多个链路；只有「从链路创建本地配置」才新建文件。编辑、启停和删除同步更新对应内容，删除时撤回生成的节点副本、策略组及组内引用，保留其他链路已分配的组名、路径名和配置修改。
- 保存链路后关闭来源订阅的自动更新，防止覆盖手动修改；删除该配置的最后一个链路时恢复之前的自动更新设置。
- 切换或重新应用配置时清空旧策略组、Provider 和布局缓存，避免加载失败时仍显示上一配置的策略组。
- 配置编辑页新增「删除节点」，链路创建页在「添加一跳」下方新增「删除已添加的节点」，均支持多选和删除前确认。配置入口操作 `proxies` 中的节点，链路入口仅操作该链路添加的外部节点。
- 每条链路在复制、删除按钮左侧新增隐藏开关，默认写入 `hidden: true`；链路仍可在手动勾选的策略组内作为子策略使用。
- 应用程序设置新增四个主页面左上角标题自定义，支持分别修改、留空隐藏和恢复默认，底部 Dock 栏名称保持原样。
