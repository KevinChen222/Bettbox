# Bettbox Smart 1.19.10

- 合入 Bettbox 1.19.10：连接页支持快速创建规则，配置支持单独设置下载选项（自定义 User-Agent、直连与证书校验），节点库支持一次导入多个节点并优先排在选择策略组前部。
- 优化网络与内核行为：TUN 支持路由 FakeIP 网段并按可达性启用 IPv6，避免复用活跃 UDP 源端口，修复测速探针卡住与 Wayland 托盘恢复黑屏问题，改进仪表盘隐藏时轮询暂停、日志精简与运行时内存统计。
- 同步 Mihomo Smart Alpha 最新上游提交（包含 FakeIP 选项与过滤器修正、xhttp 连接复用过期清理及 Linux 进程规则匹配修复），保留 Smart 自动选路、固定节点、测速与 LightGBM 模型同步。
- 本 fork 的应用内更新检查现会检测个人仓库的全部公开 Release（包含测试版与正式版），发现新版本后直接跳转到对应版本的 Release 页面。
