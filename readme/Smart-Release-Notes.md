# Bettbox Smart 1.19.4 · 链路与 fork 客户端修复

- 修复含 `(?i)` 大小写忽略过滤表达式的配置无法创建链路的问题，保留原节点和策略组名称；策略组与 Provider 过滤均支持此写法。
- 修复链路编辑页面「最大路径数」标签与「添加一跳」按钮重叠。
- 移除右上角 PRE 斜角标记。
- Android 使用独立包名 `com.kevinchen222.bettbox.smart`，显示为 Bettbox Smart，可与原版 Bettbox 同时安装。包名变更后作为新应用安装，旧应用数据需通过备份导入。
- 首次安装免责声明补充仅供开发者本人自用、不提供支持或担保及其他使用者自行承担后果的说明。
- 「关于」链接按 fork 仓库、检查更新、bettbox、Avalon、FlClash、Mihomo 排列，移除 Telegram 群组与频道链接。
- 检查更新默认读取本 fork 最新正式版，同一应用版本下也比较构建日期和序号。
- 本次替换测试版，现有正式版保持不变；Release 仅保留一个测试版和一个正式版。
